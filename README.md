# Quantum-Inspired Cyber Threat Detection Demo

## Run
```bash
python -m venv venv
```
Linux/macOS:
```bash
source venv/bin/activate
```
Windows:
```bat
venv\Scripts\activate
```
Install and run:
```bash
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`.

This is an educational quantum-inspired simulation based on the supplied project specification. It does not claim to implement a formally proven production QDS protocol or physical quantum communication system.
